bench_jgrapht_kuhnmunkres -- JGraphT 1.5.3 KuhnMunkresMinimalWeightBipartitePerfectMatching, thread clock plus collector time, column "jgrapht_kuhnmunkres_threadgc" (paper: JGraphT KM with GC)

USAGE
  [JAVA_HOME=<jdk>] bench_jgrapht_kuhnmunkres [--csv] [--tag <text>] <instance.asn>
  (the launcher fixes --solver kuhnmunkres; --human prints a block with the
  thread/gc/jit split instead of the row)

WHAT IS TIMED
  The constructor and getMatching() of the Kuhn-Munkres matcher, whose first
  step is its own |X|*|Y| cost-matrix build from getEdge(x, y) lookups.  The
  graph (SimpleWeightedGraph, hash-backed, the faster structure for those
  lookups) is filled arc by arc OUTSIDE the clock; the matcher accepts only a
  complete bipartite graph with equal sides, so on low-cost and two-cost the
  absent arcs are entered at |X|*cmax + 1 (optimum unchanged), on geometric
  nothing is added.  Before the clock the same solver is run on a seeded
  random instance through the measured function until two whole solves add
  nothing to the JIT's compilation total (60 s cap).  Clock: the solver
  thread's CPU time (ThreadMXBean) PLUS the collector's accumulated pause
  time (GarbageCollectorMXBean.getCollectionTime, whole ms); cpu_usr_ms is
  thread user time plus the collector's share.  JVM flags:
  -XX:ActiveProcessorCount=1 -XX:+UseSerialGC -Xmx24g.

COLUMNS (one CSV row per run with --csv; without it a human-readable block)

  instance      base name of the .asn file
  nodes, arcs   from its problem line
  left, right   |X| and |Y|
  theta, theta_frac
                always 0 and 0.000: they belong to the export's shortcut and
                are kept so every solver's rows have the same shape
  status        OPTIMAL, NO_PERFECT_MATCHING, or ERROR_<code> / TIMEOUT
  matched       number of matched left vertices (= |X| when OPTIMAL)
  cost          the weight of the matching, minimised
  cpu_ms        THE MEASUREMENT: CPU time between the two clock readings
  cpu_usr_ms, cpu_sys_ms   its user/system split
  wall_ms       wall-clock time over the same window; nothing is derived from it
  tag           free text copied from --tag (the campaign put "<family>;rep=<k>" there)

EXAMPLE (the campaign's raw row)
  low-cost_n2048_s1.asn,2048,22528,1024,1024,0,0.000,OPTIMAL,1024,7920,2507.834,2470.000,37.834,2508.759,low-cost;rep=1

The raw rows of the paper appendix (paper_results/hungarian_results.zip,
<column>/<family>.csv) carry two further columns appended by the campaign
runner, inferred_from and core, which the program itself does not print.
