bench_sage_oracle -- SageMath (passagemath 10.6.48) matroid intersection with the verified oracles, column "Sage (our oracle)"

USAGE
  <program> PROBLEM INSTANCE
  PROBLEM  matching | b_matching | weighted_matching | weighted_b_matching
  INSTANCE the .asn file for the two matching problems, the .bmatch file for
           the two b-matching problems (same graph, capacities stamped on)

OUTPUT (one line of key=value pairs on standard output, nothing else)
  cpu_ms   THE MEASUREMENT: CPU time, user + system, between the two clock
           readings, in whole milliseconds (rounded)
  user_ms, sys_ms   its split (not printed by the Sage programs)
  card     number of edges in the returned common independent set
  weight   sum of their weights (every weight is 1 in a .asn file without
           costs; the arc cost otherwise)
  Exit status 0 and this line on success; an error message on standard
  error and a non-zero status otherwise (the answer is checked after the
  clock: no vertex may carry more edges than its capacity).
  The published raw rows (published_results/solver_csvs.zip) add the
  columns instance, n, seed, nodes, edges, status, inferred_from and core
  written by the campaign runner; wall_ms there is the runner's wall clock.

WHAT IS TIMED
  Matroid.intersection_unweighted(M2) for the two unweighted problems,
  Matroid.intersection(M2, weights) for the two weighted ones, called on two
  OracleMatroid objects (code/sage_matroid_intersection/sage_bipartite_common.py)
  that answer Sage's independence, closure and circuit queries through Python
  transcriptions of the verified partition-matroid oracles
  (Partition_Oracle_Imp for matching, Capacity_Partition_Oracle_Imp for
  b-matching).  Clock: time.process_time immediately before and after the
  call; reading the instance (asn_reader.py), building the two matroids and
  checking the result are outside.  Sage's own answer may differ from the
  exports' in weight on the unweighted problems (any maximum-cardinality
  set is correct) and in card on the weighted ones (maximum weight over
  common independent sets); the campaign's agreement check compared card on
  the unweighted problems and weight on the weighted ones.

EXAMPLE (low-cost_n64_s1.asn, matching; the campaign row read card 32, weight 1493)
  cpu_ms=12 card=32 weight=1493
