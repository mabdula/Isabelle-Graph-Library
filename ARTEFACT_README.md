# IsaGraphLib artefact: Formally Verified Efficient Graph Algorithms in Isabelle/HOL

This artefact is the Isabelle/HOL formal development accompanying the paper. It contains the full library of verified graph algorithms, the code exported from it, and a machine-checked index that links every listing in the paper to its formal counterpart.

For the contents of the library, the publications it builds on, and how to install Isabelle and the Archive of Formal Proofs and register this development as a component, see `README.md`.

For the index that maps every listing in the paper to its formal counterpart, together with the commands that build and check it, see `Paper_Index/README.md`. Checking the whole index also builds the whole library on which it depends, so it verifies the development as well.
